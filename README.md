# Senou — landing page

Site vitrine de Senou (produit Acxa Technology) : HTML/CSS/JS statique, sans build.

- `index.html` — page unique (hero, transferts, compte & carte, comment ça marche, sécurité, FAQ, CTA)
- `css/style.css` — design tokens (navy `#141f47`, pervenche `#7a8dd0`), composants
- `js/main.js` — menu mobile, convertisseur XOF→EUR (taux fixe 655,957), animations d'apparition
- `assets/` — logo/marque Senou extraits du PDF d'identité (SVG), favicon, drapeaux
- `fonts/` — Onest (variable, latin) auto-hébergée

Aperçu local : `python3 -m http.server 4173` puis http://localhost:4173
